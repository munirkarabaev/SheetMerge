# Code Policy

## Purpose

This document defines the coding rules for this repository during implementation.

## Rules

- Use clear, well-named files and modules.
- Keep Django templates in a dedicated `templates/` folder.
- Keep view logic in a dedicated `views/` folder.
- Keep form logic in a dedicated `forms/` folder.
- Keep model logic in a dedicated `models/` folder.
- Keep files under 400 lines.
- Add docstrings to modules, classes, and functions where they add clarity.
- Use Django templates only.
- Do not introduce React.
- Do not introduce Docker.
- Do not introduce Celery.
